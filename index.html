Protocol & tests

A deliberately visible protocol

8 bits make a byte in 5.6 seconds. Each minute holds 10 physical bytes followed by 4 seconds of silence. Messages use printable ASCII and trailing space padding.

None: One message on 1200 / 1600 Hz. FDM: A uses 1200 / 1600 Hz; B uses 2800 / 3200 Hz. TDM: A and B alternate whole bytes on 1200 / 1600 Hz.

Synchronize both laptops’ system clocks first. Use wired or built-in audio; keep this tab active. There is no preamble or automatic synchronization.
